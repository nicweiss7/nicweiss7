## Selected Projects

### Stochastic Mosquito Population Model

Numerical simulation of a mosquito population model using stochastic

differential equations.

Methods:

- Euler-Maruyama method

- Milstein method

- Monte Carlo simulation

- Extinction-time analysis

### Numerical Methods for Population Dynamics

Comparison of numerical methods for a nonlinear ODE system describing

mosquito population dynamics.

Methods:

- Explicit Euler

- Implicit Euler

- Crank-Nicolson

- Convergence analysis

- Stability analysis

### Applied Time Series Analysis

Implementation and empirical analysis of econometric time series models in Python.

Methods:

- AR and MA modelling
- Least Squares and Maximum Likelihood estimation
- ACF and PACF diagnostics
- AIC, HQ and Schwarz model selection
- Residual and specification testing
- Augmented Dickey-Fuller unit root testing
- Monte Carlo simulation
